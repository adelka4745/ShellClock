## ✨ Что нового в v7 (Обновление ShellClock AI и Умных Будильников)

*   🧠 **ShellClock AI:** Встроенный ассистент с расширенным словарём фактов (от А до Я), наукой, астрономией и программированием.
*   ⏰ **Умные будильники от ИИ:** Создание реальных системных будильников через естественный язык (абсолютное время вроде *«в 8 утра»*, *«21:00»* или относительное *«через 15 минут»*, *«через 2 часа»*).
*   💻 **Генерация кода:** Написание примеров кода на Kotlin, Python, Java, C++, HTML и SQL прямо в чате.
*   💬 **Экспорт/импорт диалогов:** Сохранение истории бесед с ИИ в файлы формата `.scaidialogs`.

## 🚀 Основные возможности

Приложение включает в себя четыре главных модуля и набор полезных утилит:

| Модуль | Описание |
| :--- | :--- |
| 🕒 **Часы (Clock)** | Классическое отображение времени с индикатором батареи и темами. |
| 🌍 **Мировое время (World)** | Более 100 городов, избранные города и главный город (Pinned). |
| ⏱️ **Секундомер (Stopwatch)** | Точный секундомер с сохранением и экспортом в `.scsw`. |
| ⌛ **Таймер (Timer)** | Удобный таймер обратного отсчета с колесом прокрутки. |
| 🤖 **ShellClock AI** | Офлайн-помощник для управления, поиска, кода и будильников. |

### 🛠️ Набор Утилит
*   **Фонарик:** Быстрое включение вспышки.
*   **Компас:** Ориентация по сторонам света.
*   **Заметки:** Быстрые записи с экспортом в `.scn`.
*   **Калькулятор:** Простые арифметические вычисления.
*   **Зал Славы Мемов:** Золотая коллекция рофлов и мемов.
*   **Радио:** Онлайн-трансляции (Радиопоток).

### 🎨 Кастомизация
*   **Темы оформления:** Светлая, Тёмная, OLED-чёрная, «Северное сияние», «Закат» и др. (всего 14+ тем).
*   **Динамические цвета:** Поддержка Material You (Android 12+).
*   **Масштабирование:** Регулировка размера шрифтов и элементов интерфейса.

## 🛠 Технологический стек

*   **Язык:** Kotlin
*   **UI Framework:** Jetpack Compose (Modern Declarative UI)
*   **Design System:** Material Design 3 & Material You
*   **Архитектура:** UDF / MVVM + Compose State
*   **Будильники:** Android `AlarmManager` + `AlarmStorage`
*   **Сеть:** `HttpURLConnection` + парсинг JSON (`org.json`)

## 📦 Установка

### Для пользователей:
1. Перейдите в раздел **[Releases](https://github.com/adelka4745/ShellClock/releases)**.
2. Скачайте последний `.apk` файл версии v7.
3. Установите на устройство.

1. Клонируйте репозиторий: `git clone https://github.com/adelka4745/ShellClock.git`
2. Откройте проект в **Android Studio**.
3. Запустите сборку и тестирование.
