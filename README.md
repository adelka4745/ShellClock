# ShellClock 🕰️

**ShellClock** — это современное и функциональное приложение для Android, предоставляющее полный набор инструментов для управления временем. Приложение разработано с использованием **Jetpack Compose** и придерживается принципов Material Design 3, обеспечивая плавный и интуитивно понятный пользовательский интерфейс.

---

## 🚀 Основные возможности

Приложение включает в себя четыре основных модуля, доступных через удобную панель навигации:

### 1. 🕒 Часы (Clock)
Классическое отображение текущего времени. Идеально подходит для использования в качестве настольных часов.

### 2. 🌍 Мировое время (World Clock)
Следите за временем в разных часовых поясах. Помогает оставаться на связи с друзьями, семьей и коллегами по всему миру.

### 3. ⏱️ Секундомер (Stopwatch)
Точный секундомер с поддержкой кругов. Отлично подходит для тренировок, приготовления пищи или любых задач, требующих точного замера времени.

### 4. ⌛ Таймер (Timer)
Настраиваемый таймер обратного отсчета с уведомлением по завершении.

---

## 🛠 Технологический стек

- **Язык программирования:** Kotlin
- **UI Framework:** Jetpack Compose (Modern Toolkit)
- **Design System:** Material Design 3
- **Архитектура:** Clean Architecture / MVVM (в процессе развития)
- **Управление состоянием:** Compose State (Remember, MutableState)

## 📦 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_АККАУНТ/ShellClock.git
   ```
2. Откройте проект в **Android Studio (Ladybug или новее)**.
3. Дождитесь завершения синхронизации Gradle.
4. Запустите приложение на эмуляторе или физическом устройстве.
