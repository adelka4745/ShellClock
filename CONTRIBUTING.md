# Как внести свой вклад в ShellClock

Мы рады любой помощи! Если вы нашли баг или хотите добавить фичу:

1. Сделайте форк (Fork) этого репозитория.
2. Создайте ветку для вашей фичи (`git checkout -b feature/AmazingFeature`).
3. Закоммитьте изменения (`git commit -m 'Add some AmazingFeature'`).
4. Отправьте изменения в ваш форк (`git push origin feature/AmazingFeature`).
5. Откройте Pull Request в оригинальный репозиторий.

Пожалуйста, придерживайтесь стиля кода проекта (Kotlin + Compose).
